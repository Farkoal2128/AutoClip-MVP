# Third-party notices

The MIT license in the repository root applies to AutoClip-authored installer files. It does not relicense third-party executables, wheels, libraries, or source archives.

- Setup includes the exact Inno Setup notice and uv MIT/Apache notices under `release/notices`.
- Runtime and native release archives retain their own license/source indexes and component-specific notices. Use the index from the exact release rather than assuming notices from a different release apply.
- Publisher downloads, including Python, Microsoft Visual C++ runtime, FFmpeg CLI, and NVIDIA prerequisites, retain their original licensing and recipient acceptance requirements.
- Redistribution qualification is recorded separately from installation-test results. An unqualified candidate must not be presented as an approved distribution.
