# Security policy

## Supported releases

Security fixes target the latest full Windows release, currently v1.0.0. Superseded prereleases are not maintained. This policy does not promise a response time or ongoing support for third-party components.

## Reporting a vulnerability

Use **Report a vulnerability** on this repository's [Security page](https://github.com/Farkoal2128/AutoClip-MVP/security) if private reporting is available. If it is unavailable, open an issue requesting a private security contact without including vulnerability details. The repository owner and maintainer, [Farkoal2128](https://github.com/Farkoal2128), will arrange a private reporting channel.

Provide the affected version, Windows version, CPU or NVIDIA profile, reproduction steps, impact, and relevant sanitized logs through the private channel. Remove API keys, tokens, credentials, personal media, and identifying paths. Do not publish exploit details or sensitive logs in a public issue before coordinating disclosure with the maintainer.

For a normal installation or download failure without a security impact, use the [issue tracker](https://github.com/Farkoal2128/AutoClip-MVP/issues). Report vulnerabilities in independently acquired third-party software to its publisher as well when appropriate.
