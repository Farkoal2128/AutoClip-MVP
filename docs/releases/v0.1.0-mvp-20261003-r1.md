# Windows MVP prerelease validation

This prerelease uses the owner-selected acceptance criteria: exact package
review and local Windows installation lifecycle tests. CPU and NVIDIA passed
installation, Finish launch and health, healthy application update, failed-health
rejection without selection/runtime changes, rollback, and receipt-owned uninstall.
Installed native files and 1,225 notice/source rows were hash checked per profile.
Foreign files, prior release material, and user data were preserved.

Download `release-validation.json` and `SHA256SUMS` from this release for exact
asset, installed-receipt, review, and lifecycle identities. The tested setup SHA-256
is `5eb6f837928241b7f9b4debca3f1cb0dc80769dbcf0863f20fed6582740aa5b0`.
The immutable build receipt retains its producer-stage candidate status; final
local release qualification is recorded separately in `release-validation.json`.

The CPU first attempt correctly refused a nonempty target left by a
platform-check-generated Python cache after GPU uninstall. That cache and its
retained receipt were preserved intact outside the install target before the
separate CPU test. GPU uninstall's measured duration includes dismissal of the
preservation notice. Source/notice retention and preservation are intentional.

Tests used the existing Windows 11 host, exact locally staged archives and
cached publisher prerequisites. No VM, clean-machine, GPU inference, or media
export validation is claimed. Package review was same-session internal technical
review; historical external review gates retain their original scope. Local
timings are not estimates of user download or installation time.

All AutoClip-owned distribution and updater URLs use AutoClip-MVP. Original
publisher dependency URLs and historical provenance are retained. Publish and
verify asset sizes/digests and corresponding-source links before promoting the
generated bootstrap, application feed, and dependency manifest on `main`.
