## Changes

- Show usable API validation errors for invalid ingest settings.
- Reuse compatible full-range H.264 previews instead of unnecessarily transcoding long sources; retain older cached derivatives.
- Serialize job Retry/Delete and discarded cleanup decisions in SQLite, preserving queued jobs, kept clips, shared exports and ZIPs.
- Publish automatic captions against the captured edit revision; preserve newer user edits.
- Reject invalid caption timing before persistence, while retaining finite zero-duration words and read compatibility.
- Close and clean upload staging safely on Windows, including cancellation while background ingest still uses it.
