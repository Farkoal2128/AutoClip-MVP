# AutoClip v1.1.0: video codec compatibility fix

Fix: adds codec compatibility for previously unsupported video types and restores
missing audio in clip previews, including E-AC-3 audio in MKV files.

The app probes actual streams, copies browser-compatible streams and converts
incompatible streams using the existing FFmpeg runtime. MP4/H.264/AAC is the
default; browsers without those decoders can use WebM/VP8/Opus. Common MPEG,
transport-stream, Windows Media, Flash, Ogg and 3GPP uploads are admitted alongside
MP4/MOV/MKV/WebM/AVI. Original media and source-relative clip selections remain
unchanged. Existing projects prepare compatible previews on demand, with visible
preparation, error and retry states.

## Install and rollback

This is an application-only update for v1.0.0 and MVP r1 installations and their
application layers. Download `AutoClip-Update-v1.1.0.zip`, finish/cancel work, quit
AutoClip, extract the ZIP, and follow its `UPDATE.md`. It uses the existing
installed updater with explicit `-ManifestPath` and `-WheelPath` arguments.
Do not replace receipt-bound maintenance helpers. Rollback uses the installed
updater's `-Rollback` switch and selects the previous app layer or runtime app.

For a new machine, install the retained v1.0.0 installer, then apply this ZIP.
No new native runtime, setup executable or native component is shipped. The
root bootstrap and app feed retain v1.0.0 pins so older helpers' automatic hash
verification remains valid; obtain v1.1.0 through its versioned update ZIP.
