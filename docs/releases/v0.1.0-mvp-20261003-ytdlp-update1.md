# Draft: Settings yt-dlp updater

This owner-test application update adds **Settings > Ingest > Update yt-dlp**,
showing progress, inline failure/retry, the installed version and a restart
instruction. It reuses the installed runtime and the existing app updater.
It does not install a new native runtime. The release must remain a draft until
the owner has tested it on the other computer. Public update defaults stay on r1.

Application source commit: `71d1427b456d3f71079e9945359a6706c3fad04d` in myAutoclip.
The source distribution includes the previously shipped platform/desktop working
tree changes; their patch SHA-256 remains
`01daf0c08d6ca34932071d20a36d872901af9be927a7ab44eebe8b2b037b025e`.
Those pre-existing edits remain uncommitted in the development checkout.

Required runtime: `v0.1.0-mvp-20261003-r1`, with release-manifest SHA-256
`572a4fc6f9734331b484c8b3a3301f7dda6e2783695200962e2ba38bdd9a9970`.
New wheel: `autoclip-0.1.0.dev0-py3-none-any.whl`, 2,114,782 bytes, SHA-256
`3c57f9ec4ea85971332bb383a776b99b9965d854b4d4c3cddb5ebb6e3303e517`.
The wheel's dependency/license metadata matches the published r1 wheel exactly.
Every wheel RECORD hash and every application member's corresponding source
archive bytes were checked. Compiled UI assets are rebuilt from current source.
The draft includes the wheel, pinned app manifest, source archive, validation,
checksums, test instructions and a convenient wheel/manifest test ZIP.

## Test on the other computer

Sign into the repository owner's GitHub account and open the draft from
[AutoClip-MVP releases](https://github.com/Farkoal2128/AutoClip-MVP/releases).
Download `AutoClip-Ytdlp-Update-Test.zip` and extract it. Quit AutoClip and finish
or cancel active processing first. Open PowerShell in the extracted folder:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\AutoClip\Setup\update-app.ps1" -ManifestPath "$PWD\app-release.json" -WheelPath "$PWD\autoclip-0.1.0.dev0-py3-none-any.whl"
```

The updater checks runtime compatibility, wheel size and SHA-256, isolates
startup/database checks, then selects the new app. The expected app ID is
`app-v0.1.0-mvp-20261003-ytdlp-update1`. Reopen AutoClip normally and find the new
button under Settings > Ingest. After updating yt-dlp, restart AutoClip before
retrying the Twitch download. Updating does not guarantee a fix for that VOD.

If the required runtime or updater is missing, stop and install the MVP runtime
first. Do not use the full Update AutoClip wizard to discover this draft: its
public feed intentionally still points to the published application.

To select the previous application again, quit AutoClip and run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\AutoClip\Setup\update-app.ps1" -Rollback
```
