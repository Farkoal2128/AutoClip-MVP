# AutoClip v1.0.0 for Windows

The owner accepted the drafts and requested their consolidation into a public
full v1.0.0 release, followed by removal of the five superseded draft/prerelease
entries. The release includes resilient prerequisite inspection, the Settings
yt-dlp update button, Twitch initialization-fragment recovery, and expected
size, average transfer speed, ETA and continuing debug activity.

CPU is the default. NVIDIA retains the exact qualified prebuilt artifact and
separate vendor prerequisite terms. Native artifacts, third-party dependencies,
original notices and licensing scope are unchanged. Version 1.0.0 is consistent
across package metadata, CLI and API. The application source commit is
`7b5d09d0d49123cdd15cef61ab42a6d8a48e2361`; the source includes the previously
shipped platform/desktop patch, SHA-256
`01daf0c08d6ca34932071d20a36d872901af9be927a7ab44eebe8b2b037b025e`.

## Existing MVP and draft users

Use `AutoClip-Update-v1.0.0.zip`. Finish/cancel current work and quit AutoClip.
Extract the ZIP, open PowerShell in the extracted folder, then run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\AutoClip\Setup\update-app.ps1" -ManifestPath "$PWD\app-release.json" -WheelPath "$PWD\autoclip-1.0.0-py3-none-any.whl"
```

Reopen AutoClip. The selected application ID is `app-v1.0.0`, running on the
existing verified r1 runtime. Its exact runtime manifest hash is included in
the compatibility list. Downloaded wheel size/hash, compatibility and health
checks remain required. Older installed updaters pin their original feed bytes,
so public feed promotion alone cannot update them; keep their receipt-bound
helpers intact and supply these explicit local artifacts.

To select the previous application, quit AutoClip and run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\AutoClip\Setup\update-app.ps1" -Rollback
```

Rollback from a layered draft selects its predecessor. It does not remove every
retained app layer or migrate the native runtime. Owned uninstall continues to
preserve runtimes referenced by application layers. Fresh installations use
`AutoClip-Setup-v1.exe`; the installer refuses a different existing installation
before presenting the wizard or overwriting its maintenance files.

Application version RED failed for dev metadata; GREEN verified package, CLI
and API version. Quick local verification passed Ruff, formatting, mypy,
41 HTTP operations, 45 contract tests, 1,017 unit/regression tests and
232 integration tests. No API shape changed. The new wheel differs from the
accepted transfer-progress draft only in version metadata, RECORD and
`__init__.py`; dependencies, licenses, frontend and download code match exactly.
Wheel RECORD and source archive correspondence were verified.

The strict Inno compiler verifies both profile graphs against the actual exact
native archives, without local-candidate opt-in. The early-refusal native test
failed before the guard and passed afterward with unchanged selection/setup
hashes. Distribution tests passed all eight cases.

The original installed r1 updater passed application update, repeat no-op,
corrupt-wheel rejection, rollback, and health/home/API checks in an isolated
local Windows fixture. Upgrading from the yt-dlp, HLS and transfer-progress
drafts and rolling back to each predecessor also passed. These fixtures reuse
host development dependencies read-only and exclude shortcuts.

Exact fresh-installer lifecycle results and final publication identities are
recorded in `release-validation.json` and `SHA256SUMS` alongside the release.
The prior exact native CPU/NVIDIA lifecycle and owner-reported second-PC
acceptance retain their original scope. This release does not claim a VM,
clean-machine matrix, GPU inference, full-VOD timeline acceptance or external
legal review. Signing remains cancelled by the owner. Automatic CI remains
Windows-only; earlier runs failed an existing styled-chat render test.
