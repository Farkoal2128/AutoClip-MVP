# Draft: Twitch fallback download metrics

This historical record is superseded by [v1.0.0](v1.0.0.md). The owner requested removal of its draft/prerelease entry after verified consolidation; retained release assets and notices are listed in the v1.0.0 validation packet.

This owner-test app update restores expected size, download speed, ETA and
continuing debug activity during the FFmpeg Twitch fallback. Expected size uses
known metadata or a marked estimate from bitrate/duration or observed media
progress. Speed is average media bytes written per elapsed second; ETA uses the
existing interface. Safe activity summaries appear every five seconds and at
completion. Successful completion reports the measured output size.

It retains the working initialization-fragment recovery and Settings yt-dlp
update button. Only `pipeline/ingest.py` and wheel RECORD differ from the prior
HLS draft. Dependencies, licensing, compiled UI and native runtime are unchanged.
Keep this release a draft until the owner confirms it on the other computer.

archive includes the previously shipped platform/desktop working-tree patch,

## Apply using the installed updater

Sign into GitHub with repository-owner access, open this draft from
[AutoClip-MVP releases](https://github.com/Farkoal2128/AutoClip-MVP/releases),
and download `AutoClip-Twitch-Progress-Test.zip`. Finish or cancel the current
download/processing, then quit AutoClip. Extract the ZIP and open PowerShell in
the extracted folder:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\AutoClip\Setup\update-app.ps1" -ManifestPath "$PWD\app-release.json" -WheelPath "$PWD\autoclip-0.1.0.dev0-py3-none-any.whl"
```

Reopen AutoClip and start a Twitch VOD download. Expected size may carry the
approximation marker; speed/ETA begin once bytes and elapsed time are available.
During the FFmpeg fallback, debug activity should show percentage, bytes and
available speed/ETA roughly every five seconds. No further yt-dlp package update
is required for this change. Expected app ID:
`app-v0.1.0-mvp-20261003-twitch-progress-fix1`.

The update supports the published r1 app and the previous HLS draft on the same
runtime. Public update discovery stays on the published app; it cannot discover
owner-only draft assets. To select the previous app, quit AutoClip and run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\AutoClip\Setup\update-app.ps1" -Rollback
```
