# Draft: Twitch initialization-fragment recovery

This historical record is superseded by [v1.0.0](v1.0.0.md). The owner requested removal of its draft/prerelease entry after verified consolidation; retained release assets and notices are listed in the v1.0.0 validation packet.

This owner-test application update fixes the native HLS download failure
`Initialization fragment found after media fragments, unable to download`.
For that specific Twitch error, AutoClip retries once with FFmpeg stream copy,
preserving selected quality and browser cookies. Progress and cancellation remain
available. It includes the prior Settings > Ingest > Update yt-dlp button.
Keep this release a draft until the owner tests it on the other computer.

## Test with the installed updater

Sign into GitHub with repository-owner access and open this draft from
[AutoClip-MVP releases](https://github.com/Farkoal2128/AutoClip-MVP/releases).
Download `AutoClip-Twitch-HLS-Fix-Test.zip` and extract it. Quit AutoClip and finish
or cancel processing first. Open PowerShell in the extracted folder:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\AutoClip\Setup\update-app.ps1" -ManifestPath "$PWD\app-release.json" -WheelPath "$PWD\autoclip-0.1.0.dev0-py3-none-any.whl"
```

Reopen AutoClip normally and retry the Twitch VOD. If its native HLS download
fails with this error, status should report a retry using FFmpeg, then continue
the download. No additional yt-dlp update is required to enable this recovery.
Expected app ID: `app-v0.1.0-mvp-20261003-twitch-hls-fix1`.

This works from the published r1 app or the previous yt-dlp button draft on the
same runtime. The public update wizard cannot discover unpublished draft assets.
If the runtime/updater is absent, install the published MVP runtime first.
To select the previous app, quit AutoClip and run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\AutoClip\Setup\update-app.ps1" -Rollback
```
